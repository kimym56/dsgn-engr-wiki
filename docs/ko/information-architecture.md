# 정보 구조

> 이 문서는 [`docs/information-architecture.md`](../information-architecture.md)의 한국어 번역본입니다. 영문 원본을 기준 문서로 사용합니다.

## 목표

정보 구조는 서로 보완하는 두 가지 행동을 지원해야 합니다.

- **조회:** 전체 참고 자료 라이브러리를 효율적으로 훑거나 필터링하기
- **발견:** 분야와 편집 컬렉션을 통해 유용한 자료를 접하기

전체 텍스트 검색을 도입하기 전에도 구조를 이해할 수 있어야 합니다.

## 제안하는 최상위 내비게이션

1. **홈** — 라이브러리를 설명하고 유용한 참고 자료와 명확한 시작점을 제공합니다.
2. **탐색** — 폭넓은 분야와 편집 컬렉션을 통해 자료를 발견할 수 있게 합니다.
3. **참고 자료** — 선별된 모든 자료를 필터링할 수 있는 하나의 색인을 제공합니다.
4. **소개** — 범위, 선정 원칙, 출처 정책, 큐레이션 절차를 설명합니다.

내비게이션은 저장 방식이나 스키마 세부 사항을 노출하지 않고 방문자의 의도를 중심으로 구성합니다.

참고 자료가 많아져 탐색과 필터링만으로는 비효율적일 때만 검색을 주요 보조 수단으로 전환합니다. 초기 구조를 이해하기 위해 검색이 필수여서는 안 됩니다.

## 페이지 유형

### 홈

홈페이지는 제품 약속과 대상 독자를 알리고, 모든 참고 자료를 둘러보거나 디자인 엔지니어링 분야를 탐색하는 직접적인 시작점을 제공해야 합니다. 최근 추가되었거나 편집자가 선정한 소수의 자료를 강조할 수 있습니다.

### 탐색

탐색은 전체 색인을 보완하는 안내형 접근 방식을 제공합니다. 참고 자료를 두 가지 방식으로 묶습니다.

- **분야**는 접근성, 디자인 시스템, 인터랙션처럼 디자인 엔지니어링의 폭넓은 주제로 자료를 분류합니다.
- **컬렉션**은 목적, 질문 또는 학습 결과를 중심으로 더 작은 자료 세트를 의도적으로 선별합니다.

분야는 안정적인 분류 도구입니다. 컬렉션은 편집 성격을 가지며 더 좋은 참고 자료를 찾으면 변경될 수 있습니다. 두 방식 모두 같은 기준 참고 자료 레코드를 렌더링합니다.

### 참고 자료

참고 자료는 전체 자료 색인입니다. 유용한 경우 분야, 형식, 원문 언어 및 기타 검증 메타데이터로 필터링할 수 있어야 합니다. 필터링이 별도의 분류 체계를 만들거나 자료 데이터를 중복해서는 안 됩니다.

각 자료 카드는 출처를 열기 전에 충분히 판단할 수 있는 정보를 포함해야 합니다.

- 제목과 형식
- 게시자와, 유용한 경우 저자
- 간결한 요약 또는 관련성 설명
- 분야
- 관련 있는 경우 원문 언어와 최근 실질적 검토 날짜
- 명확한 외부 목적지
- 승인된 미리보기 이미지 또는 중립적 대체 이미지

초기 경험에서는 카드에서 외부 출처로 직접 연결할 수 있습니다. 카드가 충분한 편집 맥락을 제공할 수 없다는 사실이 테스트에서 확인될 때만 전용 로컬 참고 자료 상세 페이지를 추가합니다.

### 분야 페이지

분야 페이지는 해당 주제가 디자인 엔지니어링과 어떻게 연결되는지 설명하고 일치하는 참고 자료를 표시합니다. 분야 페이지가 참고 자료 요약을 중복하거나 소유해서는 안 됩니다.

### 컬렉션 페이지

컬렉션 페이지는 선택이나 순서가 유용한 이유를 설명하고 기존 참고 자료를 표시합니다. 컬렉션에서 참고 자료를 제거해도 기본 라이브러리에서는 제거되지 않아야 합니다.

### 소개

소개 페이지는 프로젝트의 범위, 선정 기준, 출처 및 정정 정책, 언어 방침, 자료 제안 방법을 설명합니다.

## 제안하는 URL 모델

한국어 지원이 명시적인 향후 요구사항이므로 첫 구현부터 로케일 접두사를 구조에 포함해야 합니다.

```text
/en/
/en/explore
/en/references
/en/areas/[slug]
/en/collections/[slug]
/en/about

/ko/...
```

루트 경로는 명시적인 언어 환경설정과 문서화된 기본값을 사용해 방문자를 안내할 수 있습니다. 한국어 로케일에는 `ko`를 사용합니다. `kr`은 언어 식별자가 아니라 국가 코드입니다.

검토된 번역이 존재하기 전에는 한국어 경로를 게시하지 않습니다. 언어 컨트롤은 URL을 변경하고, 서버에서 읽을 수 있는 환경설정으로 방문자의 선택을 기억할 수 있습니다. URL이 기준 언어 상태로 유지됩니다.

게시 후에는 슬러그를 안정적으로 유지합니다. 이름 변경을 피할 수 없다면 이전 URL에서 새로운 기준 URL로 리디렉션해야 합니다.

필터 상태는 `/en/references?area=accessibility` 같은 쿼리 매개변수를 사용할 수 있습니다. 필터링된 화면을 공유할 수 있어야 하며 값이 유효하지 않으면 전체 색인으로 복구해야 합니다.

## 관계 모델

관계는 명시적으로 정의하고 검증합니다.

- 참고 자료는 하나 이상의 분야에 속합니다.
- 참고 자료는 0개 이상의 컬렉션에 포함될 수 있습니다.
- 분야는 레코드를 소유하지 않고 참고 자료를 모읍니다.
- 컬렉션은 레코드를 소유하지 않고 참고 자료를 선별하고 선택적으로 순서를 정합니다.
- 번역된 프로젝트 메타데이터는 같은 기준 참고 자료 식별자를 가리킵니다.

구현은 참조된 식별자를 검증해야 합니다. 잘못된 관계가 프로덕션에 나타나지 않도록 개발 또는 빌드 검사에서 실패해야 합니다.

## 외부 이동 동작

- 외부 게시자로 이동하는 링크를 명확히 구분합니다.
- 아이콘에만 의존하지 않고 접근 가능한 링크 목적을 유지합니다.
- 추적 편의를 위해 기준 외부 목적지를 가리거나 중간 리디렉션을 거치거나 대체하지 않습니다.
- 미리보기 이미지가 없어도 프로젝트가 작성한 맥락을 표시합니다.
- 출처가 보관되었거나 일시적으로 접근 불가능한 경우 다른 자료로 조용히 바꾸지 않고 유용한 상태를 제공합니다.

## 내비게이션 원칙

- 네 개의 최상위 목적지를 안정적이고 이해하기 쉽게 유지합니다.
- 방문자가 색인과 탐색 사이를 이동할 때 가능한 경우 필터를 유지합니다.
- 분야 및 컬렉션 페이지에 이동 경로를 제공합니다.
- 필요 이상의 깊은 분류 트리를 피하고 평면적인 분야와 명시적 컬렉션을 우선합니다.
- 검색 엔진에 의존하지 않고 탐색을 통해 모든 게시 참고 자료에 도달할 수 있게 합니다.
- 키보드 포커스, 본문 바로가기, 제목 구조, 링크 목적을 기본 페이지 구조에 포함합니다.

## 의도적으로 미룬 결정

다음 결정은 검증된 라이브러리 규모와 인터랙션 디자인에 따라 달라집니다.

- 정확한 검색 또는 인덱싱 방식
- 정확한 필터 컨트롤과 정렬 옵션
- 참고 자료에 전용 로컬 상세 페이지가 필요한지 여부
- 방문자가 폼으로 자료를 제안할 수 있는지 여부
- 작성 중 메타데이터 제안을 자동화할지 여부

결정을 미룬다는 것은 요구사항을 잊는 것이 아니라 첫 스캐폴드의 범위에서 제외한다는 뜻입니다.
