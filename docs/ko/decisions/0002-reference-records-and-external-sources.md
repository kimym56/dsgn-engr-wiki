# 0002 — 참고 자료 레코드와 외부 출처 처리

> 이 문서는 [`docs/decisions/0002-reference-records-and-external-sources.md`](../../decisions/0002-reference-records-and-external-sources.md)의 한국어 번역본입니다. 영문 원본을 기준 결정 기록으로 사용합니다.

- 상태: **승인됨(Accepted)**
- 날짜: 2026-08-05
- 승인일: 2026-08-05
- 결정 책임자: 프로젝트 유지관리자

## 맥락

DSGN ENGR Wiki는 주로 웹의 다른 곳에 게시된 유용한 디자인 엔지니어링 자료를 선별합니다. 출처의 전체 콘텐츠를 복사하거나 이에 의존하지 않으면서 방문자가 자료를 판단하고 발견하는 데 충분한 프로젝트 소유 맥락을 제공해야 합니다.

외부 페이지는 변경되거나, 리디렉션되거나, 사라지거나, 유용한 메타데이터가 없거나, 부적절한 미리보기 이미지를 제공할 수 있습니다. 페이지 요청이나 프로덕션 빌드 중에 외부 페이지를 가져오면 사이트 가용성이 관련 없는 게시자에 의존하게 됩니다. 따라서 자료 데이터, 출처 표시, 미리보기, 링크 유지관리에 관한 지속적인 정책이 필요합니다.

## 결정

### 자료 레코드

선별한 모든 자료를 스키마 검증을 거친 로컬 레코드로 저장합니다. 구현 계획에서 구체적인 파일 형식을 선택하되, 스키마는 다음을 지원해야 합니다.

- 프로젝트가 소유하는 안정적인 식별자
- 제목과 기준 외부 URL
- 게시자와, 유용한 경우 저자
- 프로젝트가 작성한 요약 또는 자료가 중요한 이유에 관한 설명
- 자료 형식과 하나 이상의 디자인 엔지니어링 분야
- 선택적 컬렉션 관계
- 원문 언어
- 상태, 추가 날짜, 최근 실질적 검토 날짜
- 선택적 원문 게시 날짜
- 출처 정보와 대체 텍스트를 포함하는 선택적 미리보기 이미지 레코드

프로젝트 소유 레코드를 사이트 렌더링의 원본으로 사용합니다. 참고 자료 페이지는 방문자를 원 게시자에게 연결하며, 출처의 글, 동영상 또는 기타 실질적인 본문 콘텐츠를 복제하지 않습니다.

### 작성 및 검증

편집자는 자료를 추가하거나 검토할 때 메타데이터를 수집하고 승인합니다. 빌드는 로컬 데이터에서 필수 필드, 식별자, URL, 분야, 컬렉션 관계, 로케일 관계, 미리보기 이미지 레코드를 검증합니다.

공개 페이지 요청 중에 출처 페이지를 스크레이핑하지 않습니다. 프로덕션 빌드의 성공이 실시간 출처 또는 Open Graph 요청에 의존하지 않게 합니다. 향후 선택적 작성 도구가 메타데이터를 제안할 수 있지만, 편집자가 저장된 결과를 검토한 후에만 게시합니다.

### 링크 상태

별도의 수동 또는 예약된 유지관리 프로세스로 외부 링크를 검사합니다. 검사는 리디렉션, 지속적 실패, 검토 날짜를 실행 가능한 결과로 보고해야 합니다. 일시적인 외부 장애가 그 외에는 유효한 로컬 레코드를 무효화하거나 정적 렌더링을 막아서는 안 됩니다.

편집자는 실패한 자료를 갱신, 보관, 대체 또는 일시 유지할지 결정합니다. 외부 목적지에 접근할 수 없을 때도 공개 화면은 프로젝트 소유 맥락을 보존하고 유용한 대안을 제공해야 합니다.

### 미리보기 이미지

승인된 미리보기 이미지가 없는 참고 자료에는 프로젝트 소유의 중립적인 대체 이미지를 사용합니다.

임의의 Open Graph 이미지를 기본적으로 핫링크하지 않습니다. 출처가 제공한 이미지는 편집 검토를 통해 출처 정보, 사용, 크기, 신뢰성이 적절한지 확인한 경우에만 사용할 수 있습니다. 적절한 권한으로 이미지를 로컬에 저장할 수 있다면 검토된 로컬 자산을 우선합니다. 미리보기 실패가 제목, 게시자, 요약 또는 목적지 링크를 가려서는 안 됩니다.

## 검토한 대안

### 참고 자료마다 하나의 Markdown 또는 MDX 문서 사용

각 참고 자료에 긴 설명을 쉽게 추가할 수 있지만, 대부분은 구조화된 메타데이터와 간결한 편집 메모로 구성됩니다. 자료마다 문서를 요구하면 초기 탐색 경험을 개선하지 않으면서 작성 및 컴파일 복잡성이 늘어납니다. Markdown 또는 MDX는 편집 페이지와 컬렉션 소개에 계속 사용할 수 있습니다.

### 런타임 메타데이터 및 Open Graph 스크레이핑

실시간 스크레이핑은 일부 메타데이터를 자동으로 최신 상태로 유지할 수 있지만 지연, 일관되지 않은 결과, 보안 제어, 요청 한도, 출처 사이트에 대한 런타임 의존성을 추가합니다. 또한 제목, 요약, 미리보기에 관한 편집 판단을 대체할 수 없습니다.

### 원격 이미지 자동 핫링크

발견된 모든 Open Graph 이미지를 렌더링하면 수작업을 줄일 수 있지만, 임의의 이미지는 변경되거나, 사라지거나, 방문자를 추적하거나, 크기가 부적절하거나, 출처가 불명확할 수 있습니다. 검토된 이미지나 중립적인 대체 이미지가 더 신뢰할 수 있습니다.

### 데이터베이스 또는 CMS 레코드

데이터베이스나 CMS는 브라우저 기반 편집과 자동 수집을 지원할 수 있습니다. 초기 프로젝트에는 계정, 실시간 갱신, 복잡한 쿼리가 필요하지 않으므로 큐레이션 워크플로가 검증되기 전에는 운영 및 마이그레이션 비용을 정당화할 수 없습니다.

## 결과

- 출처 웹사이트에 접속하지 않고 버전 관리된 데이터에서 사이트를 결정론적으로 렌더링할 수 있습니다.
- 편집자는 요약, 분류, 출처 표시, 검토 날짜를 책임집니다.
- 메타데이터와 링크가 오래될 수 있으므로 링크 상태 및 실질적 검토가 지속적인 유지관리 책임이 됩니다.
- 스크레이핑된 메타데이터를 자동으로 수용하는 방식보다 자료 추가에 더 많은 편집 작업이 필요합니다.
- 같은 검증 레코드에서 탐색 및 검색 인덱스를 로컬로 생성할 수 있습니다.
- 미리보기 디자인은 중립적인 대체 이미지로도 잘 작동해야 하며 모든 자료에 이미지가 있다고 가정할 수 없습니다.
- 향후 수집 자동화는 검토 없는 게시 파이프라인이 아니라 작성 보조 도구로 유지해야 합니다.

## 검증

이 결정을 승인하기 전에 첫 구현 계획 또는 기술 검증 작업에서 시스템이 다음을 수행할 수 있는지 입증해야 합니다.

1. 완전한 샘플 자료 레코드를 검증하고 렌더링한다.
2. 선택적인 저자, 게시 날짜 또는 미리보기 이미지 데이터가 없어도 유용한 카드와 페이지를 렌더링한다.
3. 잘못된 URL, 중복 식별자, 알 수 없는 분야 또는 컬렉션 참조를 실행 가능한 오류로 거부한다.
4. 외부 페이지를 가져오지 않고 탐색 및 검색 데이터를 생성한다.
5. 차단하지 않는 링크 상태 검사로 리디렉션과 접근할 수 없는 출처를 보고한다.
6. 실질적인 제3자 콘텐츠를 복제하지 않으면서 출처 표시와 작동하는 목적지 링크를 유지한다.
7. 외부 미리보기가 없거나 실패할 때 중립적인 대체 이미지를 표시한다.
