# DSGN ENGR Wiki

**Design Engineering Wiki** is a planned educational website for designers and developers who want to learn design engineering through clear terms, connected knowledge, and practical skills.

## Project status

This repository is in the **readiness stage**. It contains product, content, information-architecture, and development-process documents only.

It intentionally does not contain:

- application source code
- a framework scaffold or `package.json`
- installed dependencies
- production content entries
- deployment configuration

Website development begins only after these documents are reviewed and an implementation plan is approved.

## Naming

- Display name: **DSGN ENGR Wiki**
- Full name: **Design Engineering Wiki**
- Repository name: `dsgn-engr-wiki`
- Optional visual shorthand: `DSGN/ENGR`
- Working description: “A practical knowledge base for learning design engineering.”

## Audience and language

The first audience is designers and developers learning design engineering. English is the canonical language for the first release. The content and URL model reserve a clear path for Korean translations later.
