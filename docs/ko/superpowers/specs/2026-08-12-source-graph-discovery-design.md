# 출처 그래프 탐색 설계

> 이 문서는 [영문 원본](../../../superpowers/specs/2026-08-12-source-graph-discovery-design.md)의 한국어 검토용 번역본입니다. 영문 원본을 기준 문서로 사용합니다.

- 상태: 승인된 설계
- 날짜: 2026-08-12
- 최초 루트 출처: `deng-design-engineering-directory`

## 배경

현재 참고자료 워크플로는 관리자가 제출한 URL에서 멈춘다. 분석한 출처가 의도적으로 자료 목록을 제공하더라도 외부 링크가 후보가 되는 것을 명시적으로 금지한다. 이 방식은 수집 범위를 통제하지만, 유용한 조사 경로를 보존하고 따라가는 것도 막는다.

참고자료 컬렉션에는 통제된 출처 그래프가 필요하다. 하나의 출처가 추가 후보로 이어질 수 있지만, 각 링크는 출처 추적 정보를 보존해야 하며 부모 출처의 신뢰도나 게시 승인을 물려받아서는 안 된다. 확장과 게시는 서로 독립된 사람의 결정으로 유지한다.

## 목표

- 참고자료와 발견된 후보를 탐색 가능한 방향 그래프로 표현한다.
- 관리자가 부모 출처의 확장을 승인하면 의도적으로 선별된 자료 링크의 첫 번째 단계를 자동 분석한다.
- 첫 단계 분석 묶음에서 발견한 자료 링크는 기록하되, 다음 확장 승인이 있기 전까지 분석하지 않는다.
- 모든 후보가 언제, 어디에서, 어떤 이유로 발견되었는지 보존한다.
- 여러 발견 경로를 잃지 않으면서 목적지를 중복 제거한다.
- 생성된 모든 분석과 번역을 사람이 검토할 때까지 내부 초안으로 유지한다.
- 외부 가져오기를 공개 애플리케이션 런타임과 프로덕션 빌드에서 분리한다.

## 비목표

- 페이지의 모든 외부 링크를 크롤링하는 것.
- 웨이브 승인 없이 링크를 재귀적으로 분석하는 것.
- 제3자 자료 목록에 포함되었다는 사실을 프로젝트의 추천으로 간주하는 것.
- 참고자료를 자동 게시하거나 제품 UI를 변경하는 것.
- 초기 구현에서 범용 크롤러, 큐 서비스, 데이터베이스 또는 CMS를 구축하는 것.
- 제3자 글, 설명, 스크린샷, 자산 또는 코드를 복제하는 것.

## 용어

### 출처 노드

안정적인 프로젝트 ID를 가진 기존 제출 출처 또는 발견 출처이다. `references/analyses/sources/` 아래의 출처 분석이 해당 노드의 지속적인 분석 산출물이다.

### 후보 노드

적격 자료 섹션을 통해 발견된 정규 URL을 위해 `references/candidates/` 아래에 두는 내부 Markdown 레코드이다. 후보는 조사 단서이며 게시된 참고자료가 아니다.

### 발견 간선

부모 출처에서 후보로 향하는 방향 관계이다. 이 간선은 발견을 유발한 섹션과 링크 맥락을 기록한다. 하나의 후보에는 여러 유입 간선이 있을 수 있다.

### 웨이브

범위가 제한된 확장 작업이다. 부모 출처의 확장을 승인하면 적격한 첫 단계 후보를 분석하는 하나의 웨이브가 시작된다. 그 후보 안에서 발견한 적격 링크는 이후 웨이브를 위해 기록하며 현재 웨이브에서는 분석하지 않는다.

### 확장 승인

다음 후보 웨이브를 검사하고 분석할 수 있도록 사람이 부여하는 권한이다. 어떤 항목의 게시도 승인하지 않는다.

### 게시 승인

분석된 후보가 공개 참고자료 레코드가 될 수 있도록 허용하는 별도의 사람 결정이다.

## 아키텍처

컬렉션은 중앙의 사람이 읽을 수 있는 색인과 분산된 Markdown 노드를 사용한다.

```text
부모 출처 분석
        |
        | 발견 간선
        v
후보 노드 ------------> 출처 분석
        |                    |
        |                    +--> 한국어 검토용 번역
        |
        +--> 게시 결정(사람 소유)
```

각 산출물의 책임은 다음과 같이 분리한다.

- `references/candidates/<candidate-id>.md`는 정규 식별 정보, 수명주기 상태, 출처 추적 간선, 분석 관계 및 게시 결정을 저장한다.
- `references/analyses/sources/<candidate-id>.md`는 프로젝트가 작성한 편집 및 웹사이트 분석을 저장한다.
- `references/analyses/ko/sources/<candidate-id>.md`는 한국어 검토용 번역을 저장하고 영문 분석을 가리킨다.
- `references/index.md`는 대기 중인 웨이브, 처리 개수, 검토 대기열 및 그래프 탐색을 요약한다.
- `references/log.md`는 추가 전용 작업 및 승인 이력을 보존한다.
- `templates/discovered-candidate.md`는 후보 형식을 정의한다.

공개 애플리케이션은 계속 승인된 참고자료 레코드만 렌더링한다. 후보 노드, 초안 분석 및 검토용 번역은 작성용 데이터이며 기본적으로 공개 콘텐츠가 아니다.

## 후보 데이터 모델

각 후보 파일은 기계가 읽을 수 있는 필드에 YAML 프런트매터를 사용하며, 사람의 메모가 필요하면 짧은 Markdown 검토 섹션을 사용한다.

필수 후보 필드는 다음과 같다.

```yaml
id: stable-candidate-id
title: Verifiable source title
title_source: destination
canonical_url: https://example.com/resource
canonical_verified: true
source_language: en
status: discovered
first_discovered: YYYY-MM-DD
last_checked: YYYY-MM-DD
analysis_path: null
translation_path: null
discoveries:
  - parent_id: parent-source-id
    parent_url: https://example.com/parent
    section: Resources
    link_text: Original link text
    encountered_url: https://example.com/original-link
    discovered: YYYY-MM-DD
    wave: 1
    depth: 1
    active: true
publication:
  decision: pending
  reviewer: null
  reviewed: null
  notes: null
```

후보 수명주기 상태는 다음과 같다.

- `discovered`: 기록되었으며 승인된 분석 웨이브에 포함될 수 있다.
- `analyzing`: 분석을 시작했지만 완료하지 않았다.
- `analyzed`: 초안 출처 분석이 존재한다.
- `inaccessible`: 목적지를 충분히 검사할 수 없었다.
- `rejected`: 후보가 다음 단계로 진행하지 않도록 사람이 결정했다.

`rejected`는 범위 밖이거나 처리하기 안전하지 않아 분석 전 또는 도중에 중단된 후보에만 사용한다. 이미 분석된 후보에는 분석 수명주기 상태를 바꾸지 않고 게시 수준의 `reject` 결정을 적용할 수 있다.

`duplicate`는 후보 수명주기 상태가 아니라 처리 결과이다. 정규화 과정에서 기존 노드를 찾으면 워크플로는 그 노드에 새로운 발견 간선을 추가하고 중복 시도를 보고한다. 두 번째 후보는 만들지 않는다.

게시 결정은 분석 상태와 독립적이다.

- `pending`
- `publish`
- `context-only`
- `reject`
- `revisit`

사람만 `pending`이 아닌 결정을 설정할 수 있다. `publish` 결정은 기존 편집 워크플로를 통해 공개 참고자료 레코드를 생성하거나 승격할 권한을 부여한다. 후보 파일 자체를 공개하는 것은 아니다.

발견 깊이와 웨이브는 후보 전체가 아니라 각 간선에 속한다. 같은 정규 후보가 서로 다른 부모에서 서로 다른 깊이로 발견될 수 있다.

`title_source`는 `destination` 또는 `parent-link`이다. 접근 가능한 정규 선언이나 리디렉션 체인을 확인하지 못한 경우 `canonical_verified`는 `false`이며, 이때 `canonical_url`은 정규화한 발견 목적지를 임시 식별자로 가진다. 이 필드는 부모 링크 문구와 임시 URL이 목적지에서 검증된 메타데이터로 오인되는 것을 막는다.

## 적격 링크 정책

외부 탐색은 출처가 학습 또는 조사 자료로 의도적으로 제시한 링크로 제한한다. 적격 맥락에는 `Resources`, `References`, `Further reading`, `Recommended` 또는 의미가 명확히 동일한 제목의 섹션이 포함된다.

다음 항목은 적격하지 않다.

- 전역 또는 지역 탐색 메뉴
- 저자 및 실무자 명단
- 글 본문에 부수적으로 포함된 링크
- 소셜 프로필
- 이미지 검색 또는 이미지 출처 링크
- 광고, 후원사, 제휴 또는 파트너
- 푸터 및 법률 링크
- 로그인, 계정 또는 유틸리티 작업

문자 그대로의 제목 일치보다 섹션의 의미를 우선한다. 의도가 모호하면 자동 분석하지 않고 사람의 판단이 필요한 항목으로 보고한다.

## 발견 및 분석 흐름

1. 관리자가 출처를 선택하고 확장 승인을 부여한다.
2. 워크플로는 접근 날짜를 기록하고 사용 가능한 부모 출처 전체를 검사한다.
3. 적격한 선별 자료 섹션을 식별하고 그 안의 모든 적격 링크를 출처에 나타난 순서대로 추출한다.
4. 표시된 링크 문구와 섹션 제목을 보존한 뒤 리디렉션과 정규 목적지를 확인한다.
5. 새로운 정규 목적지라면 부모에서 향하는 발견 간선을 포함한 후보 노드 하나를 만든다.
6. 기존 목적지라면 출처 추적 정보가 새로울 때 별도의 발견 간선을 추가한다. 완전히 같은 간선의 반복은 보고하지만 중복 저장하지 않는다.
7. 승인된 웨이브의 접근 가능한 모든 첫 단계 후보를 자동 분석한다.
8. 완료한 분석마다 영문 초안 출처 분석과 한국어 검토용 번역을 만든다.
9. 해당 하위 출처 안에서 발견한 적격 자료 링크를 다음 웨이브의 `discovered` 후보로 기록한다. 현재 웨이브에서는 그 목적지를 검사하거나 분석하지 않는다.
10. 결과와 검토 질문을 색인 및 추가 전용 로그에 반영한다.
11. 완료된 웨이브를 사람의 검토 대상으로 제시한다. 관리자가 명시적으로 결정하기 전까지 게시 결정은 `pending`으로 유지한다.

워크플로는 첫 단계 후보를 관리 가능한 작업 묶음으로 나누어 처리할 수 있다. 그러나 기록된 모든 첫 단계 후보가 해당 웨이브의 종결 결과—분석 완료, 접근 불가, 사람에 의한 거절 또는 기존 정규 노드에 연결—중 하나를 가질 때까지 웨이브를 완료로 간주하지 않는다.

## 출처 추적 및 그래프 규칙

- 모든 발견 간선은 부모 ID와 URL, 섹션 제목, 원래 링크 문구, 발견 날짜, 웨이브, 깊이 및 마지막 확인 시점의 링크 존재 여부를 기록한다.
- 후보는 부모의 권위, 품질, 분류 또는 승인 상태를 물려받지 않는다.
- 정규 URL을 주 중복 제거 키로 사용한다. 리디렉션 근거와 처음 발견한 URL은 작업 보고서 또는 검토 메모에 남긴다.
- 여러 부모가 하나의 정규 후보 노드를 가리킬 수 있다.
- 현재 조상 경로에서 이미 방문한 정규 URL은 다시 방문하지 않으며, 관계만 순환 안전 간선으로 기록한다.
- 재검사에서 링크가 더 이상 존재하지 않으면 `active: false`로 설정할 수 있지만 과거 간선을 삭제해서는 안 된다.
- 분석에서는 직접 관찰, 부모의 설명 및 프로젝트의 종합 판단을 구분한다.
- 부모가 제공한 설명은 후보를 찾는 데 도움을 줄 수 있지만 접근 불가능한 목적지에 대한 근거는 아니다.

## 실패 처리

하나의 출처가 전체 웨이브를 실패시키지 않도록 후보별로 실패를 격리한다.

- **잘못된 URL:** 발견 맥락을 웨이브 보고서와 추가 전용 로그에 보존하고 구문 또는 스킴 문제를 보고하며, 후보 노드를 만들거나 가져오지 않는다.
- **리디렉션:** 정규 목적지를 저장하고 리디렉션 근거를 보존한다.
- **중복 목적지:** 기존 노드에 새로운 출처 추적 정보를 추가하고 중복 결과를 보고한다.
- **인증 또는 유료 장벽:** 접근 조건을 기록하고 접근 통제를 우회하지 않고 직접 확인할 수 있는 내용만 분석한다.
- **크롤링 제한 또는 속도 제한:** 제한을 준수하고 접근 속도를 낮추거나 중단하며 후보를 미완료 또는 접근 불가로 표시한다.
- **이용 불가능한 출처:** 후보를 `inaccessible`로 유지한다. 검색 스니펫, 미리보기 또는 부모 페이지로 내용을 추론하지 않는다.
- **모호한 자료 섹션:** 자동 분석에서 제외하고 사람의 검토 질문으로 제기한다.
- **부분적인 묶음 실패:** 완료된 노드는 보존하고 남은 후보를 보고하며 유효한 작업을 되돌리지 않는다.
- **변경되거나 제거된 링크:** 과거 간선을 보존하고 확인 후 비활성으로 표시한다.

외부 장애는 애플리케이션 빌드 장애가 되지 않는다.

## 최초 DENG 웨이브

이 워크플로의 첫 적용 대상은 `deng-design-engineering-directory`이다.

2026-08-12에 확인한 [DENG 페이지](https://deng.theedgar.dev/)는 `Design Engineers` 아래의 실무자 명단과 `Resources` 아래의 학습 링크를 구분한다. 최초 웨이브에는 `Resources` 섹션의 링크만 포함한다. 실무자 명단, 탐색 메뉴, Google 이미지 링크 및 관련 없는 페이지 요소는 제외한다.

최초 웨이브는 다음을 수행한다.

1. 기록된 접근 시점에 표시된 적격 DENG 자료 링크를 모두 수집한다.
2. 정규 후보 노드를 생성하거나 갱신한다.
3. 접근 가능한 모든 첫 단계 목적지를 분석한다.
4. 완료된 분석의 한국어 검토용 번역을 만든다.
5. 해당 목적지에서 발견한 적격 자료 링크를 대기 중인 다음 웨이브로 기록한다.
6. `references/index.md`와 `references/log.md`를 갱신한다.
7. 두 번째 단계 목적지를 검사하거나 분석하기 전에 중단한다.

제품 UI, 레이아웃 또는 공개 참고자료 데이터 변경은 이 웨이브의 범위에 포함하지 않는다.

## 정책 변경

`references/AGENTS.md`의 외부 링크 추적 전면 금지를 이 설계의 적격 링크 및 웨이브 규칙으로 대체한다. 관리자가 제출한 URL은 계속 루트 출처를 도입하는 유일한 방법이다. 발견 후보는 승인된 확장 웨이브를 통해서만 들어올 수 있다.

`docs/content-strategy.md`에는 후보가 내부 탐색 자료라는 점과 확장 승인과 게시 승인 사이의 차이를 기록한다.

새 결정 기록은 결정 0002의 핵심 보장을 바꾸지 않고 그래프 기반 탐색을 채택한다. 로컬 승인 레코드는 계속 공개 데이터의 기준이며, 외부 접근은 작성 단계의 작업으로 유지하고 빌드는 외부 게시자의 실시간 상태에 의존하지 않는다.

기존 출처 분석 지침에는 후보 노드로 연결되고 대기 중인 다음 웨이브를 식별하는 발견 요약을 추가하되 전체 그래프 메타데이터를 중복하지 않는다.

## 검증

초기 구현은 다음 사항을 검증해야 한다.

1. 후보 파일에 모든 필수 필드가 있고 수명주기, 메타데이터 출처, 검증 및 게시 값이 알려진 값으로만 구성되어 있다.
2. 후보 ID, 정규 URL, 분석 경로 및 번역 경로가 내부적으로 일관된다.
3. 여러 부모 또는 발견 URL이 같은 목적지를 가리켜도 정규 목적지당 하나의 노드만 생성된다.
4. 서로 다른 발견 간선을 보존하면서 완전히 같은 간선은 중복하지 않는다.
5. 적격 자료 섹션은 포함하고 탐색 메뉴, 사람 명단, 소셜 링크, 광고 및 푸터 링크는 제외한다.
6. 승인된 첫 단계 이후 분석을 중단하며 더 깊은 후보는 검사하지 않고 기록만 한다.
7. 잘못된 URL, 리디렉션, 접근 불가, 제한 및 중복 목적지에 실행 가능한 결과를 부여한다.
8. 완료된 모든 영문 분석에는 올바르게 연결된 한국어 검토용 번역이 있다.
9. 색인과 로그의 개수가 후보 및 분석 개수와 일치한다.
10. 사람의 `publish` 결정과 기존 게시 워크플로 없이 후보나 초안 분석을 게시된 참고자료로 취급하지 않는다.
11. 어떤 검증이나 프로덕션 빌드도 실시간 외부 요청을 요구하지 않는다.

검증에는 Markdown 스키마와 그래프 불변 조건을 위한 픽스처 기반 자동 검사와 DENG 추출 범위에 대한 수동 검토를 함께 사용할 수 있다. 전용 크롤링 인프라는 반복 웨이브에서 구체적인 필요가 확인될 때까지 미룬다.

## 기대 결과

참고자료 컬렉션은 더 이상 분석된 단일 페이지에서 끝나지 않는다. 루트 출처에서 선별 자료를 거쳐 이후 탐색 웨이브로 이어지는 검토 가능한 경로를 보존하면서, 명확한 출처 추적, 제한된 탐색, 프로젝트 고유 분석 및 사람의 게시 통제를 유지한다.
