# 0003 — 출처 그래프 발견

- 상태: **승인됨(Accepted)**
- 날짜: 2026-08-12
- 승인일: 2026-08-12
- 결정 책임자: 프로젝트 유지관리자

## 맥락

기존 참고 자료 워크플로는 유지관리자가 제출한 URL에서 끝났습니다. 이 방식은 수집을 통제했지만, 검토한 출처가 의도적으로 제시한 연구 경로를 버렸습니다. 프로젝트는 부모 출처의 신뢰도, 품질 또는 게시 상태를 해당 링크의 승인으로 취급하지 않으면서 이 경로를 보존해야 합니다.

기존 로컬 레코드 정책은 계속 적용됩니다. 승인된 로컬 참고 자료 레코드가 공개 출처 원본이고, 외부 접근은 작성 과정의 관심사이며, 프로덕션 빌드는 실시간 외부 게시자에 의존해서는 안 됩니다.

## 결정

### 후보 노드와 발견 간선

승인된 발견 작업에 통제된 출처 그래프를 사용합니다. **후보(Candidate)**는 적격 자료 섹션을 통해 발견한 하나의 정규 URL에 대한 내부 Markdown 레코드이며, 게시된 참고 자료가 아니라 조사 단서입니다. **발견 간선(Discovery edge)**은 부모 출처에서 후보로 향하는 방향 관계입니다. 각 간선은 부모 ID와 URL, 섹션 라벨, 원래 링크 텍스트, 발견한 URL, 발견 날짜, 웨이브, 깊이, 마지막 검사 시점의 존재 여부를 기록합니다.

정규 URL을 기본 중복 제거 키로 사용합니다. 새 정규 목적지는 후보 노드 하나를 만들고, 기존 목적지는 필요한 경우 별도의 새 출처 추적 간선을 추가합니다. 동일한 간선의 반복은 보고하되 중복하지 않습니다. 재검사에서 사라진 간선은 `active: false`로 표시할 수 있지만 이력을 유지해야 합니다. 후보는 여러 유입 간선을 가질 수 있으며 부모의 신뢰도, 분류 또는 승인을 물려받지 않습니다.

### 적격 및 제외 링크

학습 또는 연구 자료로 의도적으로 제시된 링크만 자동 발견 대상입니다. `Resources`, `References`, `Further reading`, `Recommended` 또는 명확히 동등한 라벨의 섹션이 적격 맥락입니다. 섹션의 의미가 문자 그대로의 제목 일치보다 우선합니다.

전역 또는 로컬 내비게이션, 저자와 실무자 명단, 글 본문의 부수적 링크, 소셜 프로필, 이미지 검색 또는 이미지 크레딧 링크, 광고, 스폰서, 제휴사, 파트너, 푸터 또는 법적 콘텐츠, 로그인·계정·유틸리티 동작의 링크는 자동 발견하지 않습니다. 모호한 섹션은 자동 분석 대신 사람의 판단을 위해 보고합니다.

### 웨이브와 승인

**확장 승인(Expansion approval)**은 다음 후보 웨이브를 검사하고 분석할 수 있는 사람의 허가입니다. 이는 어떤 항목의 게시 승인이 아닙니다. 부모 출처를 승인하면 하나의 범위가 정해진 웨이브가 시작됩니다. 전체 이용 가능한 부모 출처를 검사하고, 적격한 첫 번째 수준 링크를 출처 순서대로 기록하며, 접근 가능한 첫 번째 수준 후보를 모두 분석합니다.

첫 번째 수준 후보 안에서 발견한 적격 링크는 다음 웨이브의 후보로 기록하지만, 추가 확장 승인이 있기 전에는 목적지를 검사하거나 분석하지 않습니다. 현재 웨이브는 캡처한 모든 첫 번째 수준 후보가 분석됨, 접근 불가, 사람에 의한 거부 또는 기존 정규 노드 연결이라는 종료 결과를 가질 때만 끝납니다. 현재 조상 경로에 이미 있는 정규 URL은 다시 방문하지 않고, 관계를 순환 안전 간선으로 기록합니다.

**게시 승인(Publication approval)**은 분석된 후보가 기존 공개 참고 자료 워크플로에 들어갈 수 있게 하는 별도의 사람의 결정입니다. 게시 결정은 `pending`, `publish`, `context-only`, `reject`, `revisit`이며, 사람만 `pending` 이외의 값을 선택할 수 있습니다. `publish` 결정만으로 후보 파일이 공개되는 것은 아닙니다.

### 후보 수명주기와 분석 번역

후보 수명주기 상태는 `discovered`, `analyzing`, `analyzed`, `inaccessible`, `rejected`입니다. `duplicate`는 수명주기 상태가 아니라 처리 결과입니다. 분석 전 또는 분석 중 범위 밖이거나 안전하지 않아 중단된 후보는 `rejected`이며, 분석을 완료한 후보에는 분석 수명주기 상태를 바꾸지 않고 게시 수준의 `reject`를 적용할 수 있습니다.

완료된 모든 영문 출처 분석에는 한국어 검토용 번역을 만듭니다. 이 번역은 내부 검토 산출물입니다. 게시된 참고 자료의 한국어 번역은 해당 영문 참고 자료 레코드가 `published` 상태가 된 후에만 시작합니다.

### 실패 처리

한 출처가 웨이브 전체를 실패시키지 않도록 후보별로 실패를 처리합니다.

- 잘못된 링크의 맥락을 웨이브 보고서와 로그에 보존하고, 구문 또는 스킴 문제를 보고하며, 후보를 만들거나 가져오지 않습니다.
- 정규 목적지를 저장하면서 리디렉션 근거를 유지합니다.
- 인증, 페이월, 크롤 제한, 요청 제한은 접근 통제를 존중하고 직접 검증 가능한 자료만 분석하며, 필요하면 접근 속도를 늦추거나 중단합니다.
- 접근할 수 없는 목적지는 `inaccessible`로 유지하고 스니펫, 미리보기 또는 부모 설명에서 내용을 추론하지 않습니다.
- 배치 일부가 실패해도 완료된 결과는 보존하고 유효한 작업을 되돌리지 않은 채 남은 후보를 보고합니다.
- 변경되거나 제거된 링크는 확인 후 역사적 비활성 간선으로 유지합니다.

외부 장애는 애플리케이션 빌드 실패가 되지 않습니다.

## 검토한 대안

### 유지관리자가 제출한 URL만 계속 수용

가장 작은 운영 범위를 유지할 수 있지만, 선별된 자료 경로를 잃고 유지관리자가 검토한 출처가 이미 식별한 링크를 수동으로 다시 제출해야 합니다.

### 모든 외부 링크를 재귀적으로 크롤링

검토하기 어렵고 부수적 링크와 선별된 링크를 섞으며 명확한 중단 지점 없이 커질 수 있습니다. 또한 제3자의 연결을 프로젝트의 추천으로 취급할 위험이 있습니다.

### 발견한 후보를 자동으로 게시

자동 게시하면 조사 단서와 승인된 참고 자료의 경계가 흐려지고, 기존 로컬 참고 자료 정책이 요구하는 편집 판단을 우회합니다.

## 결과

- 유지관리자는 루트 출처 제출, 확장, 게시 결정을 계속 통제합니다.
- 후보 레코드는 기본적으로 공개 참고 자료로 나타나지 않으면서 출처 추적과 유용한 연구 경로를 보존합니다.
- 발견 작업에는 정규화, 간선 이력, 웨이브 보고, 후보별 실패 처리라는 범위가 정해진 운영 책임이 생깁니다.
- 영문 분석이 기준이며 한국어 분석 번역은 게시 결정 전 내부 검토를 지원합니다.
- 공개 애플리케이션과 프로덕션 빌드는 실시간 외부 접근과 독립적으로 유지됩니다.

## 검증

구현은 후보 파일에 필수 필드와 알려진 값이 있는지, ID·정규 URL·분석 경로·번역 경로가 일치하는지, 하나의 정규 URL이 하나의 노드를 만들면서 서로 다른 출처 추적 간선이 보존되는지, 적격 섹션이 내비게이션·명단·소셜·광고·푸터 링크를 제외하는지 검증해야 합니다.

또한 첫 번째 수준 웨이브 중단, 실행 가능한 잘못된 URL·리디렉션·접근 불가·제한·중복 결과, 올바르게 연결된 한국어 검토 번역, 인덱스와 로그 수의 일치, 사람만 수행하는 게시, 검증이나 프로덕션 빌드의 실시간 외부 요청 부재를 검증해야 합니다.
