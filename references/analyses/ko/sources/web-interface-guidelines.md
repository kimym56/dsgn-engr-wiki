# 자료 분석: Web Interface Guidelines

## 편집 평가

### 범위 적합성

이 living checklist는 폼, 타이포그래피, 모션, 터치, 성능, 접근성, 제품 피드백 전반의 작은 인터페이스 세부 사항을 구현 선택과 연결한다. 암묵적인 craft 결정을 검토 가능한 항목으로 만든다는 점에서 디자인 엔지니어링과 직접 관련된다. 목록은 의도적으로 완전하지 않으며 널리 확립된 실천과 저자의 선호가 섞여 있으므로, 각 항목은 정책으로 그대로 채택하지 말고 맥락에 맞게 평가해야 한다.

### 권위와 지속 가능성

문서는 Rauno의 인터페이스 사이트에서 제공되고 편집 가능한 공개 저장소로 연결되지만, 페이지에는 게시일, 버전, changelog가 없다. 주기적으로 갱신되며 WAI-ARIA를 중복하지 않는다고 명시한다. Footnotes는 근거를 더하고 보조 자료로 연결하지만 많은 항목에는 출처가 없다. 브라우저와 플랫폼에 특화된 조언은 빠르게 낡을 수 있다.

### 중복 및 분류

제안 형식: `documentation`. 제안 Area: `interaction-design`, `frontend-quality`, `accessibility`, `motion`. 제안 Collection: 없음. 출처 언어: `en`. `pasito`, `vaul`, `family-wallet`에서 문서화한 구체적인 컴포넌트 동작과 중복되지만, 이 자료는 더 넓은 체크리스트 범위와 더 적은 사례별 근거를 가진다.

### 편집 권고

`review`. 가치가 높은 검토 질문 목록으로 유지하되, 각 권고는 현재 브라우저, 접근성, 제품 맥락에서 검증해야 한다는 편집 주석을 붙인다.

## 웹사이트 디자인 분석

### 정보 계층과 탐색

도입부가 범위를 정한 다음 이름이 붙은 일곱 개 주제 섹션과 마지막 `Footnotes` 섹션이 이어진다. 제목 앵커가 딥 링크를 지원하고 두드러진 전역 탐색이 없어 체크리스트에 주의가 모인다. 목록은 개별 규칙을 훑기 쉽게 하지만 우선순위나 근거 강도를 표시하지 않는다.

### UI, 인터랙션 및 모션

페이지 자체는 주로 읽기 화면이다. 콘텐츠는 토글의 즉시 적용, 액션 주변 피드백, 짧은 인터랙션 지속 시간, 자주 사용하는 액션에서 새로움 최소화, 화면 밖 애니메이션 정지, 기기 역량에 따른 동작을 권한다. 이는 출처의 주장이다. 브라우저 런타임이 없어 페이지 자체의 인터랙션과 모션을 실행하지 못했다.

### 그리드, 레이아웃 및 반응형 동작

전달된 마크업은 장식용 수평·수직 가이드 선으로 둘러싸인 하나의 `main` 영역에 내용을 배치한다. 고정 선 오프셋은 제한된 읽기 폭을 암시하며 반응형 viewport가 선언되어 있다. 실제 좁은 화면 재배치는 시각적으로 검사하지 않았다.

### 타이포그래피, 색상 및 시각적 리듬

큰 분할 제목, 섹션 제목, 밀도 높은 bullet list, inline code, footnote 표식으로 구성을 만든다. 장식 가이드 선은 `aria-hidden`으로 표시되어 시각 구조와 콘텐츠 의미를 분리한다. 정확한 글꼴, 색상, 대비는 시각적으로 확인하지 않았다.

### 접근성 관찰

전달된 마크업에서 확인한 강점은 하나의 main 영역, 계층적인 제목과 목록, 접근 가능한 footnote 관계, 레이블이 있는 돌아가기 링크, 접근성 트리에서 제외한 장식 선이다. WAI-ARIA를 대체한다고 주장하지 않는 점도 긍정적이다. disabled control과 비표준 pointer timing 등 일부 권고는 맥락에 따라 달라진다. 키보드 동작, 포커스 가시성, 대비, screen reader 출력은 런타임에서 검사하지 않았다.

### 전이 가능한 원칙

- 인터페이스 craft를 구체적이고 검토 가능한 점검 항목으로 만든다.
- 권고를 그 근거와 영향을 받는 입력 방식에 연결한다.
- 터치, hover 역량, 기기 자원, 모션 필요에 맞게 동작을 조정한다.
- 피드백을 그 원인이 된 액션 가까이에 둔다.
- 모든 규칙을 보편적으로 제시하지 말고 주관적이거나 시점에 민감한 지침을 표시한다.

### 복제하지 않아야 할 출처 고유 표현

체크리스트 문구, 정확한 섹션 구성, 장식 그리드, 분할 제목 처리, 저장소 콘텐츠, 코드 예제를 복사하지 않는다. 채택할 규칙은 독립적으로 검증해야 한다.

## 자료 발견

- 적격 섹션: `Footnotes`.
- 후보 ID: `disable-transitions-temporarily`, `next-themes`, `media-hover`, `will-change`, `safari-16-4`.
- 다음 웨이브 후보: footnotes에서만 2단계·웨이브 2 링크 5개를 기록했다. 목적지는 열지 않았고 모두 웨이브 2 검사 전까지 `canonical_verified: false`, `source_language: und`인 임시 식별 상태다.
- 제외한 링크 유형: 도입부의 WAI-ARIA와 저장소 편집 링크, 체크리스트 항목 안의 inline MDN 및 저장소 링크, 제목 앵커, footnote 돌아가기 링크, 기타 지역 탐색.

## 근거와 불확실성

- 직접 관찰: 2026-08-12에 전체 체크리스트 텍스트, 섹션 순서, footnotes, 전달된 의미 구조, 부모 페이지의 링크 목적지를 검사했다.
- 사람의 확인이 필요한 주장: 저자 귀속, 유지관리 주기, 출처 없는 항목의 근거 강도, 오래되어 유효하지 않은 권고가 있는지.
- 접근 제한: 렌더링된 인터랙션, 키보드, 반응형, 색상 대비, 모션, screen reader 테스트를 수행하지 못했다.
- 기존 분석과의 모순: 없음. Pasito가 명시한 reduced-motion 동작은 여기서 논의하는 원칙의 컴포넌트 수준 사례 하나를 제공한다.
