# 결정 기록

> 이 문서는 [`docs/decisions/README.md`](../../decisions/README.md)의 한국어 번역본입니다. 영문 원본 색인을 기준으로 사용합니다.

이 디렉터리는 지속적인 제품 및 기술 선택을 기록하여 향후 기여자가 결정과 그 근거를 함께 이해할 수 있게 합니다.

## 상태 값

- **제안됨(Proposed)** — 권장되었지만 구현을 위해 아직 승인되지 않았습니다.
- **승인됨(Accepted)** — 승인되어 현재 프로젝트에 적용됩니다.
- **대체됨(Superseded)** — 더 새로운 결정 기록으로 대체되었습니다.
- **거부됨(Rejected)** — 검토 후 의도적으로 채택하지 않았습니다.

## 결정 추가하기

1. [`templates/decision-record.md`](../../../templates/decision-record.md)를 복사합니다.
2. 다음 네 자리 식별자를 지정합니다.
3. 결정을 설명하기 전에 맥락과 현실적인 대안을 기술합니다.
4. 결과와 검증 방법을 설명합니다.
5. 이 색인에 기록을 추가합니다.

결정을 승인하려면 명시적인 검토가 필요합니다. 제안된 결정이 디렉터리에 존재한다는 이유만으로 구현 정책이 되어서는 안 됩니다.
