# Designparser 릴 학습 설계

날짜: 2026-08-12

> 이 문서는 [영문 원본](../../../superpowers/specs/2026-08-12-designparser-reel-studies-design.md)의 한국어 검토용 번역본입니다. 영문 원본을 기준 명세로 사용합니다.

## 요약

인증된 `designparser` Instagram 프로필의 공개 릴을 발견하고, 비공개 작업용 사본을 다운로드하며, Whisper로 로컬 전사하고, 장면 전환 키프레임을 추출한 뒤, 검토된 학습 내용을 Next.js 위키 안에서 릴마다 하나의 독창적인 인터랙티브 HyperFrames 슬라이드쇼로 만드는 반복 가능한 관리자 실행 워크플로를 만든다.

영어가 기준 언어이다. 라우트와 콘텐츠 모델에는 향후 검토된 한국어 번역을 위한 경로를 미리 둔다. 원본 릴, 오디오, 전사문, 추출 프레임, 브라우저 데이터, 검토되지 않은 생성 초안은 버전 관리에 포함하지 않는다. 커밋되는 위키에는 출처 자료의 미러가 아니라 출처 표시, 프로젝트 고유의 종합 내용, 독창적인 설명용 시각 자료를 담는다.

## 목표

- 인증된 `designparser` 릴 피드가 반환하는 모든 공개 릴을 피드가 끝날 때까지 페이지네이션하여 열거한다.
- 이후 실행을 증분·재개 가능하게 만들어, 완료된 작업을 다시 처리하지 않고 새 릴을 추가할 수 있게 한다.
- 다운로드한 릴 오디오를 Whisper로 로컬 전사하고, 비공개 검증을 위해 타임스탬프가 있는 세그먼트를 보존한다.
- 비공개 시각 분석을 위해 장면 전환 키프레임을 추출한다.
- 학습 레코드나 덱을 위키에 쓰기 전에 사람의 검토를 요구한다.
- 검토된 릴마다 수동으로 탐색하는 영어 덱 하나를 만든다.
- 목록에 노출되지 않는 Next.js 학습 라우트에 네이티브 HyperFrames 슬라이드쇼 동작을 임베드한다.
- 모든 요약, 원칙, 다이어그램, 적용 예시는 프로젝트 고유의 언어와 시각 자료로 표현하면서 출처를 명확히 표시한다.
- 한국어 라우트를 지금 게시하지 않으면서 향후 검토된 한국어 번역을 위한 명시적 관계를 둔다.

## 비목표

- 제작자의 릴 파일, 오디오, 전사문, 자막, 프레임, 스크린샷, 브랜딩, 시각적 정체성 또는 실질적인 문구를 복사·재게시·노출하지 않는다.
- AI가 생성한 요약이나 덱을 자동 게시하지 않는다.
- 첫 버전에서는 여러 릴을 하나의 덱으로 합치지 않는다.
- HyperFrames의 MP4 출력을 생성·렌더링·저장·게시하지 않는다.
- 학습 영역을 사이트 헤더, 푸터, References, Explore, 컬렉션, 사이트맵 또는 공개 참고자료 인덱스에 추가하지 않는다.
- 목록에 없는 URL을 접근 제어로 취급하지 않는다. 배포된 학습 URL을 아는 사람은 누구나 열 수 있다.
- 계정, 데이터베이스, CMS, 백그라운드 작업, 클라우드 전사, 임베딩, 벡터 검색 또는 자동 한국어 번역을 추가하지 않는다.
- 인증 과제, 요청 제한, 삭제된 콘텐츠, 비공개 콘텐츠 또는 플랫폼 접근 제어를 우회하지 않는다.

## 출처 및 권한 경계

수집 대상은 관리자가 제공한 다음 프로필 하나뿐이다.

```text
https://www.instagram.com/designparser/reels/
```

가져오기 도구는 관리자의 Mac에서 수동으로 실행하며, Instagram 쿠키를 위해 로그인된 기존 Chrome 세션을 읽을 수 있다. 쿠키 값, 비밀번호, 브라우저 데이터베이스 또는 재사용 가능한 세션 파일을 출력하거나 내보내거나 프로젝트에 복사하거나 커밋해서는 안 된다.

Instagram의 `reels` 프로필 피드와 브라우저 쿠키 입력을 지원하는 인증된 추출기를 사용한다. 첫 구현은 다음과 같이 구성한 `gallery-dl`을 우선한다.

- 정확한 `designparser` 프로필 URL
- 일반 게시물, 스토리, 하이라이트, 태그된 미디어, 아바타, 프로필 자산을 제외하기 위한 `include: reels`
- 쿠키 출처로 Chrome 사용
- 보수적인 요청 간격
- 페이지네이션이 끝까지 계속되도록 최대 게시물 수를 설정하지 않음

워크플로는 인증된 계정이 정상적으로 볼 수 있는 미디어만 처리한다. 로그인 과제, 동의 화면, 요청 제한, 사용할 수 없는 릴, 삭제된 릴 또는 비공개 콘텐츠 경계가 나타나면 해당 작업을 중단하거나 기록하며, 가져오기 도구는 이를 우회해서는 안 된다. 플랫폼 동작은 외부 요인이며 불안정하므로, 인증된 발견 기능은 학습 모델의 일부가 아니라 명시적으로 교체 가능한 어댑터로 둔다.

이 프로젝트에서 “모든 릴”은 실행 시점에 인증된 전체 페이지네이션 열거가 성공적으로 반환한 모든 릴 ID를 뜻한다. 삭제되었거나 제거되었거나 지역·연령 제한을 받거나 그 밖의 이유로 사용할 수 없는 자료에 대한 접근을 보장하지 않는다.

## 아키텍처

워크플로에는 세 가지 경계가 있다.

1. **비공개 추출** — git에서 제외된 캐시 안에서 릴을 발견하고, 미디어를 다운로드하고, 오디오와 프레임을 추출하고, Whisper를 실행한다.
2. **사람이 검토한 종합** — 비공개 근거를 독창적인 영어 학습 초안으로 바꾸고 관리자의 명시적 승인을 요구한다.
3. **위키 표현** — 커밋된 학습 데이터를 검증하고 목록에 노출되지 않는 locale 접두사 라우트에서 네이티브 HyperFrames 슬라이드쇼 하나를 표시한다.

추출 파이프라인은 저작 도구이며 프로덕션 런타임 의존성이 아니다. 공개 페이지 요청과 프로덕션 빌드는 Instagram에 접속하거나, Whisper 또는 `ffmpeg`를 호출하거나, Chrome을 읽거나, 비공개 캐시를 요구하지 않는다. 애플리케이션은 검토되고 버전 관리되는 학습 레코드와 덱 컴포지션만으로 결정론적으로 렌더링한다.

## 비공개 작업 캐시

워크플로의 위치는 쉽게 찾을 수 있지만 내용은 제외되도록 저장소 로컬 캐시 루트를 사용한다.

```text
.study-cache/
└── designparser/
    ├── manifest.json
    └── reels/
        └── <reel-id>/
            ├── source.json
            ├── source.mp4
            ├── audio.wav
            ├── transcript.json
            ├── transcript.txt
            ├── frames/
            │   └── <timestamp>.jpg
            └── draft.json
```

`.study-cache/` 전체를 무시해야 한다. 테스트는 이 디렉터리 바깥의 합성 픽스처를 사용하며 실제 출처 파일을 요구해서는 안 된다.

캐시 매니페스트는 정확한 프로필, 발견 시각, 릴 ID, 정규 릴 URL, 관찰된 출처 메타데이터와 단계별 상태를 기록한다. 각 단계는 `pending`, `running`, `complete`, `failed` 중 하나이며, 실패 시 타임스탬프와 간결한 오류를 포함한다. 중단된 프로세스가 남긴 오래된 `running` 상태는 안전하게 다시 시도할 수 있다.

캐시는 비공개 작업 자료이며 지속 가능한 프로젝트 지식이 아니다. 캐시를 삭제하면 추출 진행 상황은 사라지지만 위키나 빌드가 망가져서는 안 된다. 가져오기 도구를 다시 실행하면 현재 접근 가능한 출처 자료로부터 캐시를 복구한다.

## 추출 파이프라인

관리자는 선택적인 단일 릴 스모크 테스트 모드가 있는 하나의 로컬 명령을 실행한다. 명령은 다음 단계를 순서대로 수행한다.

1. **사전 점검** — 정확한 대상 핸들, 필요한 로컬 실행 파일, 쓰기 가능한 캐시, `.study-cache/`의 무시 여부를 확인한다.
2. **발견** — 사용 가능한 모든 페이지에 걸쳐 인증된 릴 피드를 열거하고 각 결과를 안정적인 릴 ID와 정규 릴 URL로 정규화한다.
3. **조정** — 새로 관찰한 ID를 비공개 매니페스트에 추가하고, 이전 레코드를 유지하며, 예상 출력이 존재하는 완료 단계를 건너뛴다.
4. **다운로드** — 한 번에 릴 하나의 원본 비디오와 최소한의 관찰 메타데이터를 저장한다.
5. **오디오 추출** — 원본 파일을 변경하지 않고 `ffmpeg`로 Whisper 호환 모노 오디오를 만든다.
6. **전사** — 로컬 Whisper를 영어 전사 모드로 실행하고 타임스탬프 JSON과 읽기 쉬운 텍스트 파생물을 저장한다.
7. **프레임 추출** — `ffmpeg` 장면 전환 감지를 사용하여 타임스탬프 기반 파일명으로 키프레임을 저장한다. 첫 버전은 모든 릴에 공통으로 적용되는 문서화된 임곗값 하나를 사용한다. 출처의 편집 스타일이 다양하므로 하나의 명령 옵션으로 보정할 수 있다.
8. **초안** — 요약, 원칙, 근거 타임스탬프, 불확실성, 제안하는 독창적 시각 자료, 4–8개 슬라이드 개요를 포함한 비공개 후보 노트를 준비한다.
9. **검토** — 커밋되는 파일을 쓰기 전에 중단하고 초안, 전사 교정, 제안 파일, 출처 표시, 덱 개요를 관리자에게 제시한다.
10. **승인된 학습 게시** — 명시적 승인 후에만 정제된 영어 학습 레코드와 HyperFrames 컴포지션을 쓰고 검증을 실행한다.

기본 배치 작업은 발견된 모든 릴을 추출할 수 있지만, 승인은 학습별 또는 명시적으로 이름 붙인 검토 배치별로 유지한다. 추출 승인은 게시 승인을 뜻하지 않는다.

## 전사 및 근거 처리

Whisper는 로컬에서 실행하며 오디오나 전사문을 클라우드 전사 API로 보내지 않는다. 첫 버전의 전사 언어는 영어다. 타임스탬프가 있는 세그먼트는 프로젝트가 작성한 주장을 검증하는 비공개 근거로 남는다.

비공개 초안은 노트를 전사 및 프레임 타임스탬프와 연결할 수 있다. 커밋되는 학습 레코드는 편집 추적을 위해 `00:12–00:18` 같은 간결한 타임스탬프 참조를 유지할 수 있지만, 그에 해당하는 복사된 문구나 프레임을 포함해서는 안 된다. 이름, 기술 용어, 명백한 인식 오류에 대한 사람의 수정은 종합 전에 비공개 초안에 기록한다.

Whisper가 신뢰할 수 있는 판독을 만들지 못하면 전사 명령이 기술적으로 완료되었더라도 해당 릴은 비공개 초안 안에서 `needs-review` 편집 상태로 남는다. 시스템은 불확실한 단어를 확정적인 주장으로 바꿔서는 안 된다.

## 커밋되는 학습 모델

승인된 각 영어 릴 학습은 Instagram 릴 shortcode 또는 미디어 ID에서 파생한 안정적인 ID와 다음 항목을 저장한다.

- `id`
- `locale: en`
- 선택적인 향후 `translationOf` 관계
- 정규 Instagram 릴 URL
- 제작자 핸들과 표시용 출처 표시
- 관찰 가능한 경우 원 게시일
- 처리일과 실질적 검토일
- 프로젝트가 작성한 제목과 간결한 요약
- 프로젝트가 작성한 핵심 원칙
- 프로젝트가 작성한 실용적 적용 방법
- 제약, 반례 또는 불확실성 노트
- 복사된 전사문이 없는 비공개 근거 타임스탬프 참조
- 순서가 있는 슬라이드 메타데이터
- 편집 상태

`reviewed` 학습만 라우팅할 수 있다. 초안 종합은 비공개 캐시에 둔다. 커밋된 학습은 비공개 캐시 경로를 참조하지 않으며 `.study-cache/`가 없어도 유효하다.

영어가 학습의 기준 언어이다. 향후 한국어 콘텐츠는 동일한 안정적 릴 ID를 사용하고 `locale: ko`를 선언하며 `translationOf`를 통해 영어 레코드를 가리키고 별도의 사람 검토를 받아야 한다. 첫 구현에서는 `/ko/studies`를 활성화하거나 언어 전환기를 노출하지 않는다.

## 덱 계약

검토된 각 릴은 정확히 하나의 HyperFrames 슬라이드쇼 컴포지션을 소유한다. 예상 덱은 다음 편집 순서에서 선택한 4–8개 슬라이드로 구성한다.

1. 주제와 출처 표시
2. 디자인 문제
3. 핵심 원칙
4. 독창적인 설명 다이어그램 또는 추상 인터페이스 모델
5. 실용적 적용
6. 제약 또는 반례
7. 핵심 요약

이 순서는 지침이며 모든 덱을 일곱 장으로 억지로 늘리라는 요구가 아니다. 모든 슬라이드는 하나의 주장과 하나의 유용한 시각 자료를 담는다. 모든 시각 자산은 프로젝트가 독창적으로 만든 HTML/CSS 도형, 타이포그래피, 다이어그램 또는 추상 표현이다. 출처 스크린샷, 추출 프레임, 복사된 UI, 브랜드 스타일, 자막, 영상은 커밋된 덱에서 금지한다.

덱은 HyperFrames 렌더러 대신 라이브 슬라이드쇼 모드와 임베드 가능한 플레이어를 사용한다. 다음을 제공해야 한다.

- 보이는 이전·다음 컨트롤
- Left/Right Arrow 탐색
- 보이는 현재 슬라이드 및 전체 슬라이드 표시
- 의미 있는 슬라이드 제목과 접근 가능한 컨트롤 이름
- 슬라이드가 활성화될 때의 짧은 진입 모션
- HyperFrames 컴포지션 계약을 통해 등록된 결정론적이며 유한한 GSAP 타임라인
- 위키 페이지 안의 반응형 컨테이너
- 모든 콘텐츠와 탐색을 유지하면서 불필요한 움직임을 제거하는 `prefers-reduced-motion: reduce` 처리

슬라이드 사이의 자동 재생은 없다. 사용자 동작이 유한한 진입 애니메이션을 재생하거나 진행시킬 수 있지만 탐색은 수동으로 유지한다. 오디오, 보이스오버, 원본 비디오, 내보내기 버튼, 렌더 스크립트 또는 `hyperframes render` 명령을 추가하지 않는다. HyperFrames 자체가 슬라이드쇼를 선형 MP4가 아니라 실시간 탐색 가능한 덱으로 문서화하므로 프로젝트도 이 경계를 지킨다.

## Next.js 라우트 및 발견

다음 영어 라우트를 추가한다.

```text
/en/studies/designparser
/en/studies/designparser/<reel-id>
```

인덱스에는 검토된 Designparser 학습만 나열한다. 개별 페이지에는 프로젝트가 작성한 맥락, 명확한 제작자 출처 표시, 정규 외부 릴 링크, 임베드된 덱, 학습 해석에 필요한 간결한 불확실성 노트를 표시한다.

학습 라우트는 의도적으로 목록에 노출되지 않는 초안이다.

- 헤더나 푸터 탐색 링크 없음
- References 또는 Explore 관계 없음
- `references/index.md` 항목 없음
- 사이트맵 항목 없음
- 페이지 메타데이터에서 `noindex, nofollow` 요청
- 덱이 Designparser의 보증을 받았거나 제휴되었다는 암시 없음

배포된 URL을 아는 사람은 누구나 라우트에 접근할 수 있다. 실제 비공개성이 나중에 필요하다면 인증 또는 배포 제외를 별도로 설계해야 한다.

## 실패 및 재개 동작

실패는 릴과 단계별로 격리한다.

- 실행 파일이 없거나 Chrome 인증을 읽을 수 없으면 수집 시작 전 사전 점검에 실패한다.
- 인증, 과제 또는 요청 제한 응답이 발생하면 일부 목록을 완전한 것으로 취급하지 않고 발견을 중단한다.
- 알려진 릴 하나의 다운로드 실패는 해당 릴의 오류를 기록하며 이미 발견된 다른 릴은 계속 처리할 수 있다.
- 오디오, Whisper 또는 프레임 추출 실패는 실패 단계를 기록하고 재시도를 위해 완료된 상위 단계 산출물을 보존한다.
- 비어 있거나 신뢰하기 어려운 전사는 검토가 필요하며 자동으로 승인된 학습을 만들 수 없다.
- 비공개 캐시가 없어도 기존 위키 라우트나 프로덕션 빌드가 망가지지 않는다.
- 잘못되거나 불완전한 커밋 학습은 로컬 검증과 빌드에 실패한다.
- HyperFrames 컴포지션 계약 또는 런타임 오류는 학습 완료로 간주하기 전에 덱 검증에 실패한다.

릴이 사라져도 가져오기 도구는 매니페스트 항목을 조용히 삭제하지 않는다. 이후 접근 실패를 기록하여 관리자가 해당 학습의 유지, 수정 또는 제거 여부를 결정할 수 있게 한다.

## 검증 및 테스트

### 가져오기 도구 검사

- 단위 테스트는 발견 결과 정규화, 안정적 릴 ID, 중복 억제, 매니페스트 파싱, 단계 전환, 오래된 실행 복구, 출력 존재 검사, 전사 타임스탬프 정규화를 다룬다.
- 합성 명령 픽스처는 Instagram에 접근하지 않고 성공적인 추출과 각 외부 실행 파일의 실패를 다룬다.
- 저장소 검사는 `.study-cache/`, 일반적인 릴 미디어 형식, 추출 오디오, 전사 파생물, 프레임, 쿠키 내보내기, 브라우저 세션 산출물이 커밋에서 무시되거나 거부됨을 증명한다.
- 전체 프로필 배치 전에 명시적으로 선택한 릴 하나를 수동 스모크 테스트로 처음부터 끝까지 처리한다.
- 완료된 전체 열거는 발견한 총수, 추출 완료 총수, 모든 명시적 실패를 보고하며 조용한 누락을 성공으로 인정하지 않는다.

### 콘텐츠 및 덱 검사

- 스키마 검증은 누락된 출처 표시, Instagram이 아닌 정규 URL, 지원되지 않는 locale, 알 수 없는 번역 관계, 복사된 미디어 경로, 잘못된 슬라이드 순서, `reviewed` 상태가 아닌 라우팅 가능한 레코드를 거부한다.
- 컴포넌트 테스트는 출처 표시, 외부 출처 링크, 슬라이드 수, 초기 상태, 이전·다음 동작, 키보드 탐색, 경계에서 비활성화된 컨트롤, 진행 상태를 검증한다.
- 모션 감소 테스트는 진입 모션을 끈 상태에서도 콘텐츠와 탐색을 사용할 수 있는지 확인한다.
- HyperFrames lint 및 런타임 검사는 MP4를 렌더링하지 않고 컴포지션 계약을 검증한다.
- 브라우저 테스트는 키보드 동작과 자동 접근성 검사를 포함하여 모바일 및 데스크톱에서 인덱스와 대표 덱 하나를 다룬다.
- 기존 format, lint, typecheck, unit, build, end-to-end 게이트를 계속 통과한다.

## 인수 조건

첫 버전은 다음 조건을 충족하면 완료된다.

1. 관리자가 Chrome에서 인증하고 현재 `designparser` 릴 피드를 완전히 열거하며 중단 후 안전하게 재개하는 문서화된 명령 하나를 실행할 수 있다.
2. 단일 릴 스모크 테스트와 전체 추출 파이프라인이 git에서 제외된 로컬 미디어, Whisper 전사문, 프레임, 초안 노트만 만든다.
3. 발견된 모든 릴은 실행 종료 시 비공개 추출 완료 또는 보이는 단계별 실패 중 하나의 상태를 갖는다.
4. 명시적인 사람 검토 없이 학습이나 덱을 커밋하지 않는다.
5. 검토된 각 릴에는 영어 학습 레코드 하나와 안정적이며 목록에 노출되지 않는 Next.js 라우트의 네이티브 HyperFrames 슬라이드쇼 하나가 있다.
6. 덱은 수동 탐색 가능하고 접근 가능하며 모션 감소를 지원하고, 프로젝트가 독창적으로 만든 글과 시각 자료만 사용한다.
7. MP4 렌더러나 생성된 비디오 출력이 없다.
8. 프로덕션 빌드와 페이지 요청은 Instagram, Chrome, Whisper, `ffmpeg` 또는 비공개 캐시 없이 동작한다.

## 검토 경계

이 설계의 승인은 로컬 추출 워크플로, 검토된 학습 모델, 목록에 노출되지 않는 Next.js 라우트, 비렌더링 HyperFrames 슬라이드쇼 통합을 위한 구현 계획 작성을 허가한다. 출처 자료 복사, 검토되지 않은 종합 게시, 공개 참고자료 라이브러리에서 학습 라우트 노출, 한국어 콘텐츠 활성화 또는 관리자가 제공한 정확한 Designparser 프로필을 벗어난 수집 확장은 허가하지 않는다.
